# Python Beginner Projects

A collection of beginner-friendly Python projects I'm building while learning programming and developing practical skills for **robotics, automation, and AI**.

## Projects

### 1. Student Marks Calculator

A simple Python program that:
- Takes a student's name.
- Accepts marks for four subjects.
- Calculates total marks and average percentage.
- Displays a pass or fail result based on the average.

**Concepts used:** Variables, user input, type conversion, arithmetic operations, and conditional statements.

### 2. Distance Alert Simulator

A Python program that simulates obstacle detection logic for a robot using manually entered distance readings.

**Features:**
- Accepts distance readings in centimetres.
- Displays STOP, WARNING, or SAFE based on distance.
- Identifies negative distances as invalid.
- Repeats readings until the user chooses to quit.

**Concepts used:** Conditional statements, comparison operators, loops, user input, and type conversion.

**Note:** This is a software simulation; it does not use a physical sensor.

### 3. Engineering Unit Converter

A Python program that converts a length entered in millimetres into other engineering units.

**Features:**
- Converts millimetres into centimetres.
- Converts millimetres into metres.
- Converts millimetres into kilometres.
- Handles invalid inputs and negative values.

**Concepts used:** Functions, arithmetic operations, user input, type conversion, conditional statements, and exception handling.

### 4. Robot Battery Monitor

A Python program that simulates a robot's battery monitoring system based on a user-entered battery percentage.

**Features:**
- Accepts battery levels from 0% to 100%.
- Displays battery health and charging recommendations.
- Warns when the battery is low or empty.
- Handles invalid input and out-of-range values.

**Concepts used:** Functions, conditional statements, comparison operators, user input, type conversion, and exception handling.

**Note:** This is a software simulation and does not measure a physical battery.
